## 🚀 My Portfolio - Tanishq Kumar
This is the source code for the personal portfolio of Tanishq Kumar, a developer specializing in Artificial Intelligence, Robotics, and Full Stack Web Development. This portfolio showcases experience, skills, and featured projects.

## 🌟 Features
1.Responsive Design: Optimized for viewing on all screen sizes (desktop, tablet, and mobile).

2.Modern Layout: Clean, professional, and visually appealing design.

3.Navigation: Smooth single-page navigation for easy access to all sections.

## Key Sections:

1.Hero: Introduction and primary focus (AI // Robotics).

2.About Me: Detailed experience (3+ years Full Stack), passion for clean code, and experience in Robotics.

3.Skills: Categorized skills including Frontend, Backend, Mobile, Tools, UX/UI, and Databases.

4.Projects: Showcase of featured work (E-Commerce Platform, Task Management App, Weather Dashboard).

5.Contact: A form for professional inquiries and social media links.

## 🛠️ Technologies Used
The portfolio is a static site built primarily with:

1.HTML5: Structure and content.
2.CSS3: Styling (via style3.css).
3.Google Fonts: For typography (Poppins and Inter).
